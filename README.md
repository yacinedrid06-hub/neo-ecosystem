# neo-ecosystem

NEO ECOSYSTEM is a bilingual digital world for personal growth, recovery, exploration, life challenges and learning. | عالم رقمي ثنائي اللغة للتعافي وتطوير الذات والاكتشاف والتعلم وتحديات الحياة.

## Run locally

This is a static web app with no build step or package installation. Open `index.html` in a browser, or start a local server from this directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. Check-ins and daily challenge progress are stored in the browser's local storage on the current device.
